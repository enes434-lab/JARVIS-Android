# JARVIS – Personal Command Center

Android/Kotlin-Prototyp mit:
- futuristischer Oberfläche
- deutscher Sprachsteuerung
- Textbefehlen
- Text-to-Speech
- Öffnen von YouTube/Google/Karten
- WLAN/Bluetooth/Einstellungen
- Dialer
- Wecker

## Start
1. Android Studio installieren.
2. Diesen Ordner als Projekt öffnen.
3. Gradle synchronisieren.
4. Smartphone per USB-Debugging verbinden oder Emulator starten.
5. App `JARVIS` ausführen.

Die App fragt beim ersten Sprachbefehl nach Mikrofon-Berechtigung.
